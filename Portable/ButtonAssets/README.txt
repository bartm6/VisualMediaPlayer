BUTTON ASSET SLOTS
==================

This folder is intentionally a set of EMPTY visual slots. The app keeps its built-in artwork until you add a replacement.
You can change button artwork without recompiling.

TO REPLACE A BUTTON IMAGE
1. Pick a slot name below, for example Play.
2. Put your file in this folder using that exact name: Play.png or Play.svg.
3. Restart VisualMediaPlayer.

Supported replacement formats: PNG, SVG, JPG/JPEG, BMP, GIF. PNG or SVG is recommended.
If both PNG and SVG exist for the same slot, PNG wins.
Transparency is preserved.
External artwork is drawn as supplied; it is not recolored or rewritten.
